## 0. 使用方法

### 0.1 必备性图例

| 标记 | 含义 |
|---|---|
| `必备` | 所有该类型条目必须有 |
| `有则必备` | 信息存在时必须著录；不存在时连同分隔符省略 |
| `可选` | 可著录，不得因省略判错 |
| `电子必备` | 电子资源必须有 |
| `电子可选` | 仅电子资源可选择著录 |
| `纸质单幅必备` | 只对纸质单幅地图强制 |

### 0.2 共通规则

- 本章模板按顺序编码制展示；表中不重复写条目序号 `[n]`。
- 方括号内的占位字段要按有无信息整体增删，不输出空标点。
- 电子资源同时写类型与载体，且获取和访问路径必备；PID 通常为电子可选。
- 先按资源出版形态路由：某报告、会议录、档案、地图或数据集若以图书/析出文献/连续出版物形式出现，优先使用相应通用模板。
- 在线出现不等于 `[EB/OL]`；先选资源类型，再加 `/OL`。

## 8.2 图书 `[M]`

### 模板

`主要责任者.题名:其他题名信息[文献类型/载体].其他责任者.版本.出版地:出版者,出版年:引文页码.访问路径.PID.`

### 字段

| 字段 | 必备性 |
|---|---|
| 主要责任者 | 有则必备 |
| 题名 | 必备 |
| 其他题名信息 | 有则必备 |
| 文献类型 | 必备 |
| 载体 | 电子必备 |
| 其他责任者 | 可选 |
| 版本 | 有则必备 |
| 出版地 | 有则必备 |
| 出版者 | 有则必备 |
| 出版年 | 有则必备 |
| 引文页码 | 有则必备 |
| 访问路径 | 电子必备 |
| PID | 电子可选 |

### 路由与检查

- 无责任者时从题名开始。
- 译者、校者等其他责任者放在类型标识之后。
- 第 1 版可省略；其他版本有则必备。
- 古籍版本照原文写“刻本”“抄本”等。
- 合订题名按 7.2.2 处理，以分号分隔。
- 在线图书用 `[M/OL]`。
- 出版年带有来源的非公元纪年时，可按 7.5.4.1 保留括注，如附录 B 的 `1865（清同治四年）`；不要将括注误删为多余年份。

### 合成示例

`陈明.知识组织方法[M].李华,译.2版.北京:示例出版社,2024:36.`

## 8.3 图书中的析出文献 `[M]`

### 模板

`析出文献主要责任者.析出题名:析出其他题名信息[文献类型/载体].析出其他责任者//图书主要责任者.图书题名:图书其他题名信息.版本.出版地:出版者,出版年:析出页码.访问路径.PID.`

### 字段

| 字段 | 必备性 |
|---|---|
| 析出文献主要责任者 | 有则必备 |
| 析出题名 | 必备 |
| 析出其他题名信息 | 有则必备 |
| 文献类型 | 必备 |
| 载体 | 电子必备 |
| 析出其他责任者 | 可选 |
| 图书主要责任者 | 有则必备 |
| 图书题名 | 必备 |
| 图书其他题名信息 | 有则必备 |
| 图书版本 | 有则必备 |
| 出版地、出版者、出版年 | 各为有则必备 |
| 析出页码 | 有则必备 |
| 访问路径 | 电子必备 |
| PID | 电子可选 |

### 路由与检查

- 析出部分与宿主以 `//` 分隔。
- 析出部分的译者等写在 `//` 前。
- 宿主图书不重复写文献类型标识。
- 章节没有责任者时，从章节题名开始。
- 在线章节通常用 `[M/OL]`，URL 放在条目末部。

## 8.4 连续出版物 `[J]` / `[N]`

本节著录整种期刊、报纸等连续出版物，不是其中一篇文章。

### 模板

`主要责任者.题名:其他题名信息[文献类型/载体].起始年,卷(期)—终止年,卷(期).出版地:出版者,出版年范围.访问路径.PID.`

### 字段

| 字段 | 必备性 |
|---|---|
| 主要责任者 | 有则必备 |
| 题名 | 必备 |
| 其他题名信息 | 有则必备 |
| 文献类型 | 必备 |
| 载体 | 电子必备 |
| 年卷期或其他标识 | 有则必备 |
| 出版地、出版者、出版年 | 各为有则必备 |
| 访问路径 | 电子必备 |
| PID | 电子可选 |

### 路由与检查

- 仍在出版：保留开放范围，如 `1984,1(1)—` 与 `1984—`。
- 已终止：写完整起讫卷期和出版年范围。
- 出版范围使用长连接号 `—`；不要把 OCR 的汉字“一”当成连接号。
- 整种在线期刊用 `[J/OL]`。

## 8.5 连续出版物中的析出文献 `[J]` / `[N]`

### 通用模板

`析出文献主要责任者.析出题名:析出其他题名信息[文献类型/载体].析出其他责任者.连续出版物题名:其他题名信息,年,卷(期/版次):页码或文章编号.访问路径.PID.`

### 字段

| 字段 | 必备性 |
|---|---|
| 析出文献主要责任者 | 有则必备 |
| 析出题名 | 必备 |
| 析出其他题名信息 | 有则必备 |
| 文献类型 | 必备 |
| 载体 | 电子必备 |
| 析出其他责任者 | 可选 |
| 连续出版物题名 | 有则必备 |
| 连续出版物其他题名信息 | 有则必备 |
| 年卷期/版次与页码等 | 有则必备 |
| 访问路径 | 电子必备 |
| PID | 电子可选 |

### 期刊定位格式（8.5.1）

| 情形 | 格式 |
|---|---|
| 年、卷、期、页 | `2001,2(1):5-6` |
| 无期号 | `2014,510:356-363` |
| 无卷号 | `2010(6):23` |
| 中文增刊 | `2012,22(增刊2):81-86` |
| 西文增刊 | `2024,12(S1):7-11` |
| 文章编号 | `2023,267:147370` |
| 只有在线出版日期 | `2024-05-09` |
| 合期/合卷 | `2001(8/9/10):36-39` |
| 同刊连续部分 | `2011,33(2):20-25;2011,33(3):26-30` |

上表 `356-363` 忠实复现 8.5.1.1 示例 2；同一标准的 8.5.2 示例 `[9]` 和附录 B.4 `[17]` 对同一篇论文写作 `356-362`。这是源文冲突，不是两种页码格式，处理原则见 core-rules.md 第 15 节。

### 报纸

使用：

`责任者.篇名[N/载体].报纸名,YYYY-MM-DD(版次).访问路径.PID.`

### 页码语义

- 阅读型参考文献可写文章起讫页或起始页。
- 引文参考文献应写实际引用信息所在页。
- 无页码而有文章编号时，把文章编号放在页码位置。
- 在线优先版和正式卷期版可能是两个独立资源；不要无提示合并。

## 8.6 会议录 `[C]`

### 先路由

若会议录或会议论文实际以图书、图书析出文献、连续出版物或连续出版物析出文献形式发表，分别用 8.2—8.5。只有不属于这些形态时才用直接会议模板。

### 直接会议模板

`主要责任者.题名:其他题名信息[文献类型/载体]//会议名称,会议年份:引文页码.访问路径.PID.`

### 字段

| 字段 | 必备性 |
|---|---|
| 主要责任者 | 有则必备 |
| 题名 | 必备 |
| 其他题名信息 | 有则必备 |
| 文献类型 | 必备 |
| 载体 | 电子必备 |
| 会议名称 | 有则必备 |
| 会议年份 | 有则必备 |
| 引文页码 | 有则必备 |
| 访问路径 | 电子必备 |
| PID | 电子可选 |

### 检查

- 会议名称前用 `//`。
- 会议年份前用逗号。
- 整本会议录与会议论文都使用 `C`，由字段结构区分。
- 在线形式用 `[C/OL]`。

## 8.8 报告 `[R]`

### 先路由

报告若以图书、图书析出文献、连续出版物或连续出版物析出文献形式出现，用 8.2—8.5。其他报告用本节直接模板。

### 直接报告模板

`主要责任者.题名:其他题名信息:报告编号[文献类型/载体].发布日期:引文页码.访问路径.PID.`

### 字段

| 字段 | 必备性 |
|---|---|
| 主要责任者 | 有则必备 |
| 题名 | 必备 |
| 其他题名信息 | 有则必备 |
| 报告编号 | 有则必备 |
| 文献类型 | 必备 |
| 载体 | 电子必备 |
| 发布日期 | 有则必备 |
| 引文页码 | 有则必备 |
| 访问路径 | 电子必备 |
| PID | 电子可选 |

### 检查

- 报告编号前用 `:`。
- 发布日期完整时用 `YYYY-MM-DD`。
- 表 7 和直接报告模板没有出版地/出版者字段；但 8.8.3 示例 `[4]` 在直接报告条目中保留了 `Springfield: ... , 1990:25`。这是标准模板与示例自身的不一致，不应仅因条目出现出版项判错；先核对资源形态和来源记录，无法裁决时列为待核。详见 core-rules.md 第 15 节。
- `[R/OL]` 本身不触发引用日期要求。

## 8.9 标准 `[S]`

### 模板

`标准编号 标准名称[文献类型/载体].访问路径.PID.`

### 字段

| 字段 | 必备性 |
|---|---|
| 标准编号 | 必备 |
| 标准名称 | 必备 |
| 文献类型 | 必备；在标准化文件中可选 |
| 载体 | 电子必备 |
| 访问路径 | 电子必备 |
| PID | 电子可选 |

### 检查

- 标准编号与标准名称之间为空格，不加句点。
- 不另加责任者、出版地、出版者或重复出版年。
- 编号中的年份是编号的一部分，保留原连接符和语言版本标识。
- 在线标准用 `[S/OL]`。

### 字段

| 字段 | 必备性 |
|---|---|
| 专利申请者/所有者 | 必备 |
| 题名 | 必备 |
| 其他题名信息 | 有则必备 |
| 专利申请号 | 必备 |

| 引文页码 | 有则必备 |

## 8.11 网站与网页 `[EB]`

### 先路由（8.11.1）

网页承载的图书、期刊论文、会议录、学位论文、报告、标准、专利、档案、地图、数据集、预印本，按其专门类型著录。只有一般网站、网页及其内容才用本节。

### 网站模板（8.11.2）

`主要责任者.题名:其他题名信息[文献类型/载体].(创建或修改日期)[引用日期].访问路径.`

| 字段 | 必备性 |
|---|---|
| 主要责任者 | 有则必备 |
| 题名 | 必备 |
| 其他题名信息 | 有则必备 |
| 文献类型 | 必备 |
| 载体 | 必备 |
| 创建或修改日期 | 有则必备 |
| 引用日期 | 必备 |
| 访问路径 | 必备 |

网站模板没有 PID 字段。

### 网页模板（8.11.3）

`主要责任者.题名:其他题名信息[文献类型/载体].(创建或修改日期)[引用日期].访问路径.PID.`

| 字段 | 必备性 |
|---|---|
| 主要责任者 | 有则必备 |
| 题名 | 必备 |
| 其他题名信息 | 有则必备 |
| 文献类型 | 必备 |
| 载体 | 必备 |
| 创建或修改日期 | 有则必备 |
| 引用日期 | 必备 |
| 访问路径 | 必备 |
| PID | 可选 |

### 检查

- 整站和单页都常用 `[EB/OL]`。
- 无正式题名的图片等可自拟题名，并把题名本身置于方括号。
- 引用日期不能由当前日期自动替代；使用实际访问事实。
- 本次审校或代理检索发生在今天，不等于论文作者今天访问；未经用户确认不得写入。
- 软件本体可用 `[CP/OL]`，下载网页可用 `[EB/OL]`；先明确著录对象。

| 题名 | 必备 |
| 其他题名信息 | 有则必备 |
| 档号 | 有则必备 |
| 文献类型 | 必备 |

## 8.13 地图 `[CM]`

### 先路由

凡以图书或图书中的析出文献形式出现的地图，分别按 8.2 或 8.3 的结构著录；其他地图用本节。路由改变字段结构，不改变资源类型：地图册和书中析出地图仍保留 `[CM]` 或相应电子载体组合，不机械改成 `[M]`。

### 模板

`主要责任者.题名:其他题名信息.比例尺[文献类型/载体].版本.出版地:出版者,出版年.尺寸.访问路径.PID.`

### 字段

| 字段 | 必备性 |
|---|---|
| 主要责任者 | 有则必备 |
| 题名 | 必备 |
| 其他题名信息 | 有则必备 |
| 比例尺 | 有则必备 |
| 文献类型 | 必备 |
| 载体 | 电子必备 |
| 版本、出版地、出版者、出版年 | 各为有则必备 |
| 尺寸 | 纸质单幅必备 |
| 访问路径 | 电子必备 |
| PID | 电子可选 |

### 检查

- 比例尺位于类型标识之前，如 `1:25 000[CM]`。
- 尺寸位于出版项之后，如 `128 cm×84 cm`。
- 在线地图用 `[CM/OL]`，不因 URL 改成 `[EB/OL]`。
- 例如标准示例 `内蒙古自治区地图册[CM].新版.北京:中国地图出版社,2006.` 采用图书结构，但类型仍是 `[CM]`。

## 8.14 数据集 `[DS]`

### 先路由

数据集若以图书、图书析出文献、连续出版物或其析出文献形式出现，用 8.2—8.5；其他数据集用本节。

### 模板

`主要责任者.题名:其他题名信息[文献类型/载体].版本.发布平台(发布或修改日期)[引用日期].访问路径.PID.`

### 字段

| 字段 | 必备性 |
|---|---|
| 主要责任者 | 有则必备 |
| 题名 | 必备 |
| 其他题名信息 | 有则必备 |
| 文献类型 | 必备 |
| 载体 | 电子必备 |
| 版本 | 可选 |
| 发布平台 | 电子可选 |
| 发布或修改日期 | 有则必备 |
| 引用日期 | 必备 |
| 访问路径 | 电子必备 |
| PID | 电子可选 |

### 检查

- 版本可写 `V1.0` 等；版本存在但省略不一定构成强制错误，因为本表列为“可选”。
- 平台与圆括号日期之间不加句点。
- 引用日期是必备字段。
- 缺失引用日期时报告待核，不得用当前系统日期、本次审校日或数据发布日期代填。
- DOI/CSTR 可单列、嵌入 URL 或直接构成访问路径；按 7.9 判断是否需要重复。

## 8.15 预印本 `[PP]`

### 模板

`主要责任者.题名:其他题名信息[文献类型/载体].版本.出版平台(创建或修改日期)[引用日期].访问路径.PID.`

### 字段

| 字段 | 必备性 |
|---|---|
| 主要责任者 | 有则必备 |
| 题名 | 必备 |
| 其他题名信息 | 有则必备 |
| 文献类型 | 必备 |
| 载体 | 电子必备 |
| 版本 | 有则必备 |
| 出版平台 | 电子可选 |
| 创建或修改日期 | 有则必备 |
| 引用日期 | 必备 |
| 访问路径 | 必备 |
| PID | 电子可选 |

### 检查

- 与数据集不同：预印本版本“有则必备”，不是普通可选。
- 平台可省略；不要因缺少 arXiv/bioRxiv 等平台名直接判错。
- 引用日期和访问路径必备。
- 缺失引用日期时报告待核，不得以本次审校日期代填。
- 正式期刊版与预印本是不同资源；分别使用 `[J/OL]` 与 `[PP/OL]`。

## `G`、`CP`、`DB`、`Z` 路由

附录 A.1 列出汇编、计算机程序、数据库和其他类型代码，但第 8 章没有为四类另设统一模板。审校时按资源实际出版/呈现形态选择有标准依据的结构，并保留真实类型代码；不得只凭代码生成字段。

- `CP/OL` 可在确属网页呈现时采用 8.11 的字段顺序；标准 8.11.3 的 Zotero 下载页示例即如此。
- `G`、`DB`、`Z` 不能一律套用图书或网页模板。先确认著录对象、宿主和载体；无法确认时保留事实并列为待核。
- 具体选择原则和边界见 [codes.md](codes.md)。

## 著者-出版年制适配

第 8 章模板默认顺序编码制。改用著者-出版年制时：

1. 保留上述类型、字段顺序和必备性。
2. 把出版年放到责任者后，以逗号分隔：`责任者, 年.题名...`。
3. 从原出版项位置删除同一出版年，不重复。
4. 图书的 `出版地:出版者,出版年:页码` 变为 `出版地:出版者:页码`。
5. 期刊的 `刊名,年,卷(期):页码` 变为 `刊名,卷(期):页码`。
6. 学位授予年等承担出版年功能的年份相应前移；完整公告日、创建/修改日、引用日仍保留在其专门字段。
7. 对只提供完整日期的电子资源，可从可靠日期取得正文标引年份，但不要删除模板要求的完整日期。
8. 没有发布/创建年份时，不把引用日期年份擅自当作出版年；标为待核并服从出版物的无日期规则。
9. 无责任者时使用 `佚名`/`Anon` 或相应词，不以题名直接承担著者-出版年标引。

正文标引和排序细则见 [citation-systems.md](citation-systems.md)。
