## 1. 适用范围与概念

### 1.1 范围（第 1 章）

- 用于作者和编制者著录参考文献。
- 不作为图书馆员、文献目录编制者或索引编制者的专业目录规则。
- 同时覆盖参考文献条目与正文标引体系。

### 1.2 区分用途（3.9、3.12）

- **引文参考文献**：作者实际引用的信息资源。
- **阅读型参考文献**：作者阅读过或供读者进一步阅读的信息资源。

用途会影响放置位置和页码：引文参考文献可集中在文后/书末，也可置于页下注；阅读型参考文献应置于文后、章后或书末。期刊文章作为引文参考文献时，页码应指向被引用信息所在页；作为阅读型参考文献时，可著录文章起讫页或起始页（8.5.1.1）。

### 1.3 区分结构

- **析出文献**：主文献的一部分，如期刊论文、书中独立篇章。
- **电子资源**：以数字方式存储、经计算机/网络/相关设备使用的资源。
- **永久标识符（PID）**：独立于当前物理位置、用于持久访问的标识符，如 DOI、URN。

## 2. 规范性强度

按下表判定，不得擅自提升强度。

| 原词 | 审校处理 |
|---|---|
| 应、不得、不应、必备 | 判为强制错误 |
| 有则必备 | 该事实存在时强制；事实不存在时不补空项 |
| 电子资源必备 | 资源属于电子形式时强制 |
| 宜、不宜 | 判为建议；保留有依据的例外 |
| 可、可选 | 多种形式均合法；只在用户要求统一时选择一种 |
| 通常 | 作为默认规则，允许信息源或专门条款覆盖 |

字段表中的“必备性”优先于只看模板的直觉。模板列出的是字段位置，不表示每个位置在所有条目中都必须出现。

## 3. 信息源

### 3.1 基本顺序（4.1—4.4）

1. 以被著录的信息资源本身为信息源。
2. 图书、连续出版物、会议录、学位论文、报告、标准、专利、网站、网页、档案、地图、数据集、预印本，应依据题名页、版权页、封面等主要信息源。
3. 图书或连续出版物中的析出文献，可从析出文献本身取其作者/篇名，从主文献主要信息源取出处。
4. 电子资源可依据存储介质上提供的主要信息源。

### 3.2 审校边界

- 把“可由题名猜测”与“由信息源确认”分开。
- 仅做格式审校时，不补造缺失作者、日期、版本、页码、出版地、URL 或 PID。
- 元数据冲突时，列出冲突来源；不要无提示地选择更顺眼的一项。
- PDF 页眉、数据库导出标签、网页导航文字不自动视为题名或责任者。

## 4. 文字与数字

### 4.1 语种（5.1）

- 使用信息资源本身的语种著录。
- 不因论文正文为中文而擅自翻译外文题名、刊名、机构名。
- 若用户需要双语参考文献，将译名视为额外出版要求，不称其为 GB/T 7714—2025 的默认要求。

### 4.2 数字（5.2）

- 原则上保持资源原有数字形式。
- 连续出版物卷期号、页码、出版年、创建/修改日期、引用日期、顺序编码制序号等宜用阿拉伯数字。
- 日期著录应符合 GB/T 7408.1。为把该引用标准落实为机器检查，本 skill 将完整日期规范化为 `YYYY-MM-DD`，月份、日期使用两位数字；这是依据引用标准展开的实施规则，不是 GB/T 7714—2025 第 5.2 条的逐字原句。

### 4.3 拼写、缩写与大小写（5.3—5.6）

- 中国人名用汉语拼音著录时，宜按 GB/T 28039。
- 机关团体、出版地后的省/州/国名、出版者可用国际公认缩写。
- 西文期刊名可按 ISO 4 缩写；全称与合规缩写不要混杂在同一表中，除非来源或出版要求如此。
- 西文大小写按原语种习惯；不要批量套用 APA 的 sentence case 或 title case。

## 5. 标识符号

### 5.1 前置符原则（6.1）

标识符号是下一字段的前置分隔符。删除空字段时，一并删除只为该字段服务的分隔符。

- 著者-出版年制的第一个字段前不加符号。
- 顺序编码制的条目序号置于方括号，如 `［1］`。

### 5.2 符号用途（6.2）

| 符号 | 放在什么字段之前/之间 |
|---|---|
| `.` | 题名、比例尺、其他责任者、析出文献其他责任者、版本、出版信息、年卷期或其他标识、尺寸、访问路径、PID 之前；条目末尾可使用 |
| `:` | 其他题名信息、出版者、页码、学位授予单位、报告编号、专利申请号、档号、收藏者之前 |
| `,` | 同一著作方式的责任者之间；“等”“译”或对应词之前；出版年之前；连续出版物及其析出文献中的年和卷号之前；会议年份、学位授予年之前 |
| `;` | 同一责任者的合订题名之间；同刊连续部分的后续年卷期与页码之前 |
| `//` | 析出文献出处或会议名称之前 |
| `()` | 连续出版物及其析出文献中的期号/版次、创建/发布/修改日期、非公元纪年出版年 |
| `[]` | 文献序号、类型/载体、引用日期、自拟信息 |
| `/` | 合期号或合卷号之间；类型与载体代码之间 |
| `-` | 起讫页码、正文连续引文序号之间 |

### 5.3 字符形态

标准规定符号功能，实际排版可能使用全角或半角字形。除非用户或出版模板指定，不要仅因 Unicode 字符宽度不同判为实质错误。应优先检查字段顺序、符号角色和文档内一致性。

## 6. 责任者

### 6.1 个人姓名（7.1.1）

- 使用“姓在前、名在后”。
- 西文著录：姓完整著录且首字母大写；名可缩写为首字母。仅首字母无法识别时，可录全名。第 7.1.1 条没有对西文姓名另写“缩写点省略”一句，但该条示例均省略名首字母后的点；按示例统一时应说明这是示例支持的实施选择。
- 欧美姓名的中文译名可只录姓，名可用首字母且缩写点省略。同姓不同名的欧美责任者，其中译名不仅应著录其姓，还应著录其名的首字母；该要求不以“已经发生混淆”为前提。
- 汉语拼音：姓完整且首字母大写；名宜用全称，如 `Li Jiangning`。
- 保留复姓、连接号、前缀和后缀的身份信息；不要用简单的“最后一个词就是姓”算法强改。

### 6.2 人数与责任方式（7.1.2）

- 同一著作方式不超过 3 人时，应全部著录。
- 超过 3 人时，可著录前 3 人，再加 `，等` 或对应词（如 `, et al.`）。
- “可”表示允许截断，并不禁止全部著录。
- 作者、编者、译者等不同责任方式分别处理；不要把译者计入作者人数。
- 使用 `et al.` 时保留 `al.` 的点。欧美姓名中文译名的名首字母按 7.1.1 明文省略缩写点；西文姓名的首字母无点形式按上节所述属于标准示例支持的实施选择。

### 6.3 匿名（7.1.3）

- 著者-出版年制：责任者不明时写 `佚名` 或相应词，如 `Anon`。
- 顺序编码制：可省略匿名责任者，直接从题名开始。
- 不要把 OCR 误识别的“供名”当成规范词。

### 6.4 机关团体（7.1.4）

- 通常照信息源著录。
- 由上至下分级著录。
- 非汉字机关团体的上下级间用 `.`；汉字机关团体名称不使用该层级点号。

## 7. 题名

### 7.1 主标题（7.2.1）

- 按信息源所载内容著录。
- 无题名时可自拟，但必须置于方括号，如 `［某照片说明］`。
- 书名号、引号等若属于题名本身，应与字段分隔符区分。

### 7.2 合订与并列题名（7.2.2）

- 同一责任者的多个合订题名：著录前 3 个，以 `;` 分隔。
- 不同责任者的多个合订题名：可只录第一个或显要位置题名。
- 不著录并列题名。不要把封面上的平行外文题名自动追加到中文题名后。

### 7.3 其他题名信息（7.2.3）

副题名、说明题名文字、多卷书分卷名、卷次、册次等放在主标题之后，以 `:` 引出。

## 8. 类型与载体

- 按附录 A 的代码著录；完整代码表见 [codes.md](codes.md)。
- 文献类型标识必备；标准文献在“标准化文件”中的特殊可选情形见 formats.md。
- 电子资源同时著录文献类型和载体，如 `[J/OL]`、`[M/CD]`，不能只写 `[OL]`。
- 类型取决于资源形态，不取决于发现它的平台。数据库中的论文仍按论文类型处理。

## 9. 版本

### 9.1 一般资源（7.4）

- 第 1 版可不著录；著录第 1 版也不因此自动构成错误。
- 其他版本说明有则必备。
- 版本宜用阿拉伯数字、序数缩写形式或其他标识表示，如 `3版`、`V1.0`、`5th ed`、`Rev. ed`。

### 9.2 古籍

按原文客观著录“写本”“抄本”“刻本”“活字本”等，不现代化改写。

## 10. 出版信息

### 10.1 基本顺序（7.5.1）

一般结构为：

`出版地: 出版者, 出版日期`

同一逻辑还用于：

- 学位论文的授予单位所在地、授予单位、授予年；
- 报告的发布日期；
- 专利的公告/公开日期；
- 档案的收藏者所在地、收藏者、形成日期；
- 数据集的发布平台；
- 预印本的出版平台。

专门类型模板可改变字段组合；不要强行给所有资源补齐“地:者,年”。

### 10.2 出版地（7.5.2）

- 著录出版者所在地的城市。
- 同名城市宜附省、州或国名限定。
- 多个出版地宜只录第一个或显要者。
- 无出版地：中文可写 `[出版地不详]`；外文可写 `[S.l.]`（末字符为小写字母 l）。
- 无出版地的电子资源可省略该项。

### 10.3 出版者（7.5.3）

- 可照原形式或使用国际公认简化/缩写。
- 多个出版者宜只录第一个或显要者。
- 无出版者：中文可写 `[出版者不详]`；外文可写 `[s.n.]`。
- 无出版者的电子资源可省略该项。

### 10.4 出版年（7.5.4）

- 使用公元纪年和阿拉伯数字。
- 另有纪年时，将原纪年放在圆括号内，如 `1947（民国三十六年）`。
- 年份无法确定时，可依次选版权年、印刷年、估计年。
- 版权年可写 `c1988`；印刷年可写 `1995 印刷`；估计年置于方括号，如 `[1936]`。

## 11. 日期

### 11.1 完整日期（7.5.4.2、7.6）

下列日期使用 `YYYY-MM-DD`：

- 期刊在线出版日期；
- 报纸出版日期；
- 报告发布日期；
- 专利公告/公开日期；
- 档案形成日期；
- 电子资源创建、发布、修改和引用日期。

### 11.2 括号角色

- 创建/发布/修改日期：圆括号 `(2025-01-02)`。
- 引用日期：方括号 `[2025-02-03]`。
- 非公元纪年：紧随公元出版年置于圆括号。

不要把正文顺序编码 `[12]` 与引用日期 `[2025-02-03]` 混为同一语义。

## 12. 页码与文章编号

### 12.1 一般要求（7.7）

- 析出文献页码和引文页码使用阿拉伯数字。
- 页码前用 `:`，范围用 `-`。
- 引自序言或扉页题词时，可照实际写 `序2-3`、`第1版自序`、`扉页` 等。
- 附录 B 示例还出现 `1.1-1.36` 一类层级式页码；不要把其中的点误判为小数点或擅自改成普通整数页码。
- 无页码但有文章编号时，将文章编号放在页码位置，如 `12:giad067`。

### 12.2 引文与阅读型差异（8.5.1.1）

- 引文参考文献：著录引用信息所在页。
- 阅读型参考文献：可录文章起讫页或起始页。

若用户给出整篇论文页码却未说明具体引文页，不要臆测；标为“需确认引用用途/引文页”。

## 13. URL 与永久标识符

### 13.1 获取和访问路径（7.8）

- 按互联网中的实际路径著录。
- 合并由排版换行拆开的 URL；移除软换行产生的空格或连字符前，先确认它不是 URL 的真实字符。
- 不把数据库检索页自动替换成 DOI 链接，除非完成事实核实并说明规范化选择。

### 13.2 PID（7.9）

- URL 已包含 DOI/URN 等 PID 时，可不重复著录 PID。
- URL 不含 PID 时，可按原文如实著录 PID。
- PID 前使用 `.`。
- `https://doi.org/...` 与另列 `DOI:...` 同时出现是可简化项，不是强制错误。
- 不擅自改变 PID 内部字符、版本后缀或大小写；只做展示规范化时保留可逆映射。

## 14. 合法变体与常见误判

以下情况不应直接判错：

- 责任者超过 3 人时全部著录，或前 3 人加“等/et al.”。
- 第 1 版被省略，或在来源明确时被著录。
- 电子资源没有出版地/出版者而省略对应字段。
- 多个出版地/出版者只录第一个或显要者。
- URL 已含 PID，因此没有另列 DOI/URN。
- URL 与 PID 重复出现。
- 条目末尾使用或不使用句点。
- 西文期刊名使用全称或符合 ISO 4 的缩写。
- 符号使用全角或半角字形但语义、顺序和全文风格一致。
- 图书出版年后按 7.5.4.1 保留来源的非公元纪年括注，如 `1865（清同治四年）`。
- 输入或出版要求采用同一序号下的中、外文完整对照双条著录；附录 B.4 `[11]` 展示了这种结构，但它不是 7.2.2 所称的并列题名，也不是所有文献都必须生成的默认形式。
- 页码采用来源可核实的层级式编号，如 `1.1-1.36`。

以下通常属于强制问题：

- 电子资源缺少载体代码。
- 有 1—3 位同一责任方式的责任者却无依据漏录其中一人。
- 非第 1 版且版本明确，却省略版本。
- 自拟题名、估计出版年未用方括号。
- 要求完整日期的字段不符合 `YYYY-MM-DD`。
- 条目类型与资源实际形态不符，或使用附录 A 不存在的代码。

## 15. 已知源文歧义

- 标准 6.2 在“自拟信息”相关交叉引用中出现 `7.5.4.4`，但正文没有该款；估计出版年的实质规则位于 7.5.4.3。审校时引用实质条款，不复制不存在的款号。
- 标准只说条目末尾“可”使用句点，因此不得将统一末句点包装成强制要求。
- 标准示例常以角标排版正文标记，但顺序编码制的规范核心是“序号置于方括号”；是否以上角形式呈现还应服从出版模板。
- 第 8.8.2 条表 7 与 8.8.3 的直接报告格式均未列出版地、出版者，但 8.8.3 示例 `[4]` 在报告编号和 `[R]` 后仍著录 `Springfield: U.S. Department of Commerce National Information Service, 1990:25`。这是模板与示例的源文不一致；不应仅因直接报告保留出版项就判错，应核对来源形态并将该项列为待核。
- 第 8.5.1.1 条示例 2 将同一篇 *Nature* 论文的页码印作 `356-363`，且注 2 明示该串代表页码；第 8.5.2 条示例 `[9]` 与附录 B.4 `[17]` 却印作 `356-362`，后者也与该论文真实页码相符。忠实转录某一处均不能靠格式规则裁决；能核实资源本身时按资源更正并记录依据，不能核实时报告源文冲突。
