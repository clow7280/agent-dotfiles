# 中文学术写作技能的维护说明

这份说明写给维护者，模型调用技能时只读取 `SKILL.md`，不会读到本文件。
修改 `SKILL.md` 时遵守下面三条原则。

## 表达符合自身

`SKILL.md` 本身的文字必须满足它提出的全部要求。
它禁止的写法，规则正文里也不能出现，例如以“标签：内容”开头的段落、需要读者回头重读的多层定语，以及密集出现的抽象主语句。
新增或改写的内容在提交前，要按 `SKILL.md` 中“起草与修订”一节的自检步骤检查一遍。

## 清晰明确，不废话不重复

每条规则只写在一处，其他位置需要时只写小节名作引用。
新增规则前，先找有没有相近的条目，有就合并，不另起一条。
例子只保留能说明边界的代表性条目，删掉以后不影响理解的说明文字也一并删去。

## 随模型与 Harness 迭代

这份技能针对的是当前大语言模型的写作习惯，模型和智能体 Harness 更新以后，这些习惯也会变。
新一代模型发布后，用它实际写几段学术文本，再对照 `SKILL.md` 逐条检查。
已经不再出现的痕迹，删掉对应条目或压缩例子；新出现的痕迹，补进“常见痕迹”的相应小节。
Harness 改变技能的加载方式时，比如 frontmatter 字段或引用文件的读取规则有变，同步调整文件结构。
