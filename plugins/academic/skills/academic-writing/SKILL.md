# 中文学术写作

文中的痕迹清单不可能穷尽所有情况，遇到未覆盖的可疑写法时，回到基本原则判断。

## 基本原则

大语言模型写出的文字之所以空泛，多半是因为它用统计上最稳妥的表达代替了具体的思考。
所以，起草和修改的方向是一致的：把空泛、装饰性、需要读者推断的表达，换成具体、直接、字面成立的表达。

落到内容上，具体的表达只能来自具体的事实。
因此，事实、数据与结论只来自用户提供的素材或待修改的原文，不补充看似合理但没有来源的信息。
修辞也服从同一要求，比喻、强调与标点可以使用，但不能替代事实和论证。

落到语气上，学术文本使用中性、准确的语体，但这不等于把所有文本改成同一种腔调。
作者原有的学科术语、立场与论证习惯都要保留，也不故意加入错误或口头禅来模仿真人。

## 写作流程

### 动笔前的判断

动笔前，先从用户要求和已有材料中判断四件事，能确定的不要求用户重复提供。
第一件是文体和当前所写的部分，即期刊论文、学位论文、文献综述还是研究报告，以及摘要、引言、方法、结果还是讨论。
部分确定之后，这一部分的论证目标通常随之明确，是提出问题、报告结果、比较方法，还是建立一个判断。
论证目标决定写什么，读者则决定写多细。
默认读者是同领域的研究者，写作前要判断他们已经知道什么、卡在哪里，不虚构一个知识水平过低的读者，也不解释同行显然知道的内容。
最后还要分清素材来源，哪些是实验数据和已核实的文献，哪些只是推测或转述，这决定了文中的判断能写得多确定。

信息不足时，选择不改变事实与作者立场的保守写法。
只有不同判断会导致实质不同的写法，且保守写法无法兼顾时，才向用户确认。

### 起草与修订

起草新文本和修改已有文本走同一套流程。

1. 按动笔前的判断确定论证目标，先想清楚各段之间如何推进，再写句子
2. 起草或改写；改写时保留原文的核心信息与作者立场
3. 逐句自检，对照“句段要求”的四条和“常见痕迹”中的用词与句式问题
4. 逐段自检，对照“段落与篇章”一节
5. 通读全文，检查章节分工、结尾与称呼是否一致，然后修订所有标记处
6. 交付成稿；修改他人文本时附上简要的改动说明

### 完整示例

下面是一段待修改的结果描述。

> 核心发现：本研究构建的融合框架显著提升了分类性能。这一框架有效捕捉了模态间的深层关联，该机制驱动了模型表征能力的跃升，这种设计更是重塑了多模态学习的范式。此外，在两个公开数据集上，准确率分别提高 3.2 和 2.7 个百分点。值得注意的是，参数量增加了 40%。

修改后的版本只保留原文已有的事实。

> 本研究将多种模态的特征融合后用于分类。在两个公开数据集上，融合后模型的准确率分别提高 3.2 和 2.7 个百分点。这一提升并非没有代价。模型的参数量增加了 40%。

修改时删去了段首的“核心发现：”标签。
原文连续三句以框架、机制、设计为主语，作出的判断都没有实验支撑，“驱动了跃升”“重塑了范式”的搭配也说不出口，所以一并删除。
“此外”把支撑结论的数据误标为补充信息，改为直接陈述。
参数量增加与准确率提高之间是转折关系，原文用“值得注意的是”一笔带过，改写后补了一句交代二者的关系。

## 句段要求

下面四条是硬性要求，起草和自检时都要逐条执行。

### 句间连接

两个判断相邻时，如果后一句不是前一句的直接延续，中间必须有一句话交代二者的关系，说明它是转折、因果还是补充。
读者不应该自己去猜两句话之间的关系。
问题与回答之间也是如此，提出问题后，至少隔一句话再展开回答。

起连接作用的这句话必须交代关系本身。
“下面来看另一个方面”这类只起导航作用的过渡句不算数，仍按“口语词与套话”一节删除。

例如下面两句之间是转折关系，原文没有交代。

> 该方法在小样本场景下表现稳定。训练时间是基线方法的 3 倍。

补上一句之后，读者不必再猜。

> 该方法在小样本场景下表现稳定。这种稳定性需要付出额外的训练开销。它的训练时间是基线方法的 3 倍。

问与答之间的停顿也是同样的写法。

> 为什么截断率越高，奖励方差反而越低？这与截断样本的奖励计算方式有关。截断样本的奖励统一记为 0，截断率越高，取值为 0 的样本越多，方差随之降低。

### 修饰语层数

一个名词前的定语最多嵌套两层。
需要三层以上时，先用一句话把最内层的概念说清楚，再往外加。
“用户行为数据分析模型优化方案”这类写法禁止出现。

按这条要求，原句“本文提出了一种用户行为数据分析模型优化方案”应拆成两句。

> 本文研究的模型用于分析用户行为数据。针对这一模型，本文提出了一套优化方案。

### 抽象主语

同一段内，以抽象概念作主语、搭配动作动词的句子不超过两句。
“这个框架吞噬了……”“这条规则抓住了……”“这个机制驱动了……”单独看都没有问题，密集出现时，读者的理解负担会不断累积。
从第三句起，主语必须换成具体的人、事物或场景。

学术文本也不把动机、意愿与感受赋予模型、指标、程序或数据。
遇到这类表述时，把动作还原为可观测的量与条件。

| 原表述                   | 改写                             |
| ------------------------ | -------------------------------- |
| 天生需要几百到上千次采样 | 该信号所需的采样量为几百到上千次 |
| 一旦超就制造出参差       | 截断发生时奖励方差增大           |
| 24 步训练只挪动 0.05     | 24 步训练后正确率变化为 0.05     |
| 超得越彻底反而越稳定     | 截断率越高，奖励方差越低         |

### 搭配自检

写完后逐句检查名词与动词的搭配，问自己这个搭配在日常口语里说不说。
说不出口的搭配，换成说得出口的。
每个字都认识、连在一起却别扭的表述，就是需要换的。

这项检查针对的是搭配本身是否成立，并不要求改用口语词。
“差值为 0.030”“该结果支持原假设”这类书面说法搭配成立，照常使用。

| 原表述                         | 改写                         |
| ------------------------------ | ---------------------------- |
| 实验结果夯实了这一假设         | 实验结果支持这一假设         |
| 该方法打通了标注与训练两个环节 | 该方法把标注结果直接用于训练 |
| 模型的鲁棒性实现了跃升         | 模型的鲁棒性明显提高         |
| 该指标承载了模型的泛化能力     | 该指标反映模型的泛化能力     |

## 常见痕迹

下列写法在大语言模型生成的学术文本中出现频率很高。
每一类都给出判断方法和改法，例子只用来说明边界，不必逐字匹配。

### 夸大意义与空泛评价

这类表达常带有“填补了空白”“具有重要的理论意义和实践价值”“标志着”“里程碑”“开辟了新路径”“奠定了坚实基础”“深远影响”“彰显”“前景广阔”等词。
大语言模型习惯在事实之后追加一句评价，宣称它重要、深刻或具有范式意义。
判断时删掉这句话，看信息量有没有减少，没有减少就直接删。
句尾追加的抽象评论同样处理，如果评论确有依据，就把依据写成独立的事实句。
“挑战与展望”式的模板段落也要删，只保留其中可核实的事实。

引言和结论是例外，这两处确实需要说明研究意义。
这时不能一删了之，而要写清楚这项研究解决了谁的什么问题，依据是什么。

下面这句话只有前半句是信息。

> 该数据集包含 12 万条样本、覆盖 8 个领域，规模庞大、质量上乘，为后续研究奠定了坚实基础。

删去后半句的评价，信息量没有减少。

> 该数据集包含 12 万条样本，覆盖 8 个领域。

### 模糊归因与未查明的因果

“研究表明”“学界普遍认为”“有观点认为”“大量研究证实”这类说法把观点挂在无名的权威身上。
学术文本中的观点都要有出处。
引用他人观点时写明具体文献；找不到出处的，改写成作者自己的判断并给出依据，或者删除。
罗列一串文献编号来壮声势、却不说明各篇具体结论的写法，处理方法相同。

原因尚未确认时，直接写“原因尚未查明”，不补充听起来合理但未经验证的解释。
前文已写明原因未查明的，后文也不在其他现象上追认因果。
后续章节如果查明了机制并给出验证过程，相应结论可以保留。

| 原表述                     | 改写                       |
| -------------------------- | -------------------------- |
| 原因不复杂，是因为……       | 删除该句                   |
| 这可能也解释了前文那个现象 | 该现象与截断的关系尚未验证 |

### 术语与自造概念

概念已有通用说法时，使用通用说法，不用口语描述、比喻或临时命名替代。
一个说法如果需要读者推断它指什么，就改为直接说明所指的事实。

| 原表述               | 改写                        |
| -------------------- | --------------------------- |
| 超长度               | 截断                        |
| Ray 的端口会跟自己撞 | 多个任务的 Ray 抢占同一端口 |
| 刷奖励               | 奖励被优化但评测指标未改善  |
| 8 个不同血统         | 8 个不同基座的模型          |
| 已经吃掉一半空间     | 已覆盖一半区间              |
| 误差范围还盖着基准线 | 置信区间与基线重叠          |

大语言模型还会把普通现象压缩成听似正式的概念，例如“监督悖论”“加速陷阱”“能力鸿沟”，用命名代替解释。
临时概括不能写成已有术语。
确实需要简称时，先给出操作性定义，并说明这是本文使用的称呼。

比喻只用来帮助理解当前内容，不作为术语在全文反复替代原概念。
同一比喻多次出现时，保留最有效的一处，其余改回实际对象。
称呼同理，同一对象在全文使用同一个名称，不为避免重复而轮换说法，表头、分类名与状态标签也保持同一套用词。

### 对比与戏剧化句式

“是 X，不是 Y”“不仅……更是……”一类结构靠对比制造强调。
写作时直接写出观测结果，需要比较时给出两侧的具体取值。
“更关键的是”“这才是问题的本质”“很多人没有意识到”等说法同样如此，它们先宣告某项发现重要，再让读者等待结论。
这类过渡句如果只用于制造悬念，直接删掉；确要判断某项因素更关键，说明比较对象和依据。

自问自答、连续否定、独立短句和重复句首也属于戏剧化节奏。
单次出现可能是作者有意的修辞，连续出现或只为制造强调时才改。
没有引入真实疑问的问题直接删除，改为陈述答案；真实的研究问题按“句间连接”的要求，在问与答之间留出一句。
多个短句表达同一层意思时，合并为完整的句子。

| 原表述                                               | 改写                                 |
| ---------------------------------------------------- | ------------------------------------ |
| 梯度对齐：是噪声，不是信号                           | 梯度对齐的三项检查结果均在噪声范围内 |
| 越稳定的指标越挑不出东西，越挑得出东西的指标越不稳定 | 重合率与取值数量呈反向关系           |
| 结果呢？很严重。                                     | 错误率从 2% 上升到 11%               |
| 没有解释。没有证据。只有结论。                       | 这项结论没有附带解释或证据           |

### 口语词与套话

口语词在学术文本中往往表达不出确切含义，应改为量值或标准说法。

| 原表述                           | 改写                         |
| -------------------------------- | ---------------------------- |
| 赢得很干脆                       | 差值为 0.030                 |
| 基本上等于抓阄                   | 接近随机选取                 |
| 本来就分不出高下                 | 真实差距低于可分辨范围       |
| 有事后找补的嫌疑                 | 该切分方式在观察结果之后确定 |
| 既然预测这条路走不通，那就退一步 | 删除该句，直接进入实验设置   |

“此外”“然而”“值得注意的是”“综上所述”“深入探讨”“至关重要”“不可或缺”“赋能”这类词单独出现并无问题。
它们在模型生成的文本中密度异常高，而且常常成串出现，所以要逐个检查能否删除或换成更朴素的说法。
其中“此外”最需要核对，它只表示补充，前后实际是因果或转折时，必须换成准确的连接词。

其余常见的套话按下列方式处理。

- 不承载信息的填充短语与教学腔直接删除，如“需要指出的是”“下面逐步分析”“不妨这样理解”
- 名词化的动词改回动词，“对……进行了优化”写作“优化了”，“起到了促进作用”写作“促进了”
- 用“作为……”“扮演着……的角色”回避简单的“是”和“有”时，改回“是”和“有”
- 层层叠加的限定词只保留一个与证据强度相符的，如“可能在一定程度上或许会”只留“可能”
- 不用“一句话概括”“简单来说”后接对仗短句的方式收束，确需总结时用陈述句写进段落
- “从 X 到 Y”的两端不在同一尺度上时，改为直接列举

### 段落与篇章

模型生成的段落常以“标签：内容”开头，例如“核心发现：……”“方法局限：……”“研究结论：……”。
这样写会把本该写进首句的信息压成一个名词。
修改时把标签的意思写进段落的第一句；如果它确实是一个独立的部分，就升级为小标题。
列表项机械地以“**名词**：”开头属于同一问题，标签没有分类作用时，改成普通句子。

要点列表只用于确实并列、彼此独立且与顺序无关的条目，例如实验参数和样本纳入标准。
论证、因果、递进与比较都写成段落。
把一段论证拆成几条孤立的要点后，条目之间的关系就丢了，读者看不出思路怎样从一点推进到下一点。
反过来，确属并列的信息也不必改写成以“首先、其次、最后”开头、结构相同的几段。

段落结构和段内句式同样不能千篇一律。
模型常常让每段都先给结论句，再列三条理由，最后用一句话收束，段内又多是长度相近的主谓宾陈述句。
实际写作中，段落应按内容组织，有的从现象写到解释，有的从问题写到回答，有的先摆数据再下判断。
句子长短随信息量变化，但不为制造变化而轮换同义词或插入修辞。
并列项的数量同样由内容决定，不为凑足三项而补入，也不为避开三段式而删成两项。

在章节层面，开头不预告本节内容，结尾也不复述刚写过的结论。
学位论文的章末小结和全文的结论部分是例外，但它们要给出由前文推导出的判断或后续工作，而不是逐项重述正文。

重复还有一种不那么明显的形式，就是把一个观点靠更换措辞、例子或比喻扩写成多个段落或章节。
检查每一段是否增加了新事实、新论证或新的限定条件，没有新增内容的段落合并或删除。

类比和案例的堆叠也是同一类问题，连续列举再多也代替不了论证。
每个类比都要说明它与当前问题对应的条件和不对应的边界，只支持同一结论的多个类比保留最贴切的一个。

### 标题、表格与格式

章节标题、表头与分类名使用中性的名词短语，如“实验设置”“结果”“讨论”“局限”。
需要读者推断含义的称呼，改为直接的名词短语。

| 原表述               | 改写             |
| -------------------- | ---------------- |
| 坑、代价和教训       | 问题、影响       |
| 怎么做的             | 实验设置         |
| 重挑一次还剩多少重合 | 重采样后的重合率 |
| 有几种不同取值       | 取值数量         |
| 做通了               | 已完成           |
| 没有买到想要的       | 结论待定         |

箭头、表情符号与连续标点如果只用于制造视觉强调，改为文字或删除。
破折号、冒号、问号与感叹号按语义使用，单次出现不必删除，只处理连续或模式化的滥用。

### 对话残留

成稿正文中不能出现聊天语句。
常见的有三类：协作语气，如“希望这对你有帮助”“如果需要我可以进一步展开”；模型自述，如“截至我的知识截止日期”；讨好开场，如“这是一个很好的问题”。
这类内容一律删除，不需要替换。
