## 1. 先确定用途和体系

### 1.1 放置位置（9.1）

- 引文参考文献可集中在文后/书末，也可分散在页下端。
- 阅读型参考文献应放在文后、章后或书末。
- 不要把延伸阅读条目自动并入正文编号，除非它实际被引用。

### 1.2 两种体系

- **顺序编码制**：正文用序号，文后表按正文首次出现顺序排列。
- **著者-出版年制**：正文用责任者与年份，文后表按文种、责任者字顺和出版年排列。

不要在同一独立参考文献表中无说明地混用两套主体系。脚注编号、公式编号、注释编号不等于顺序编码制文献号。

## 2. 顺序编码制

### 2.1 单篇引用（9.2.1.1）

1. 按文献在正文中首次出现的先后连续编码。
2. 将序号置于方括号，如 `[1]`。

标准示例以角标展示方括号序号，但条文的强制核心是“序号置于方括号”。具体是否上标仍可服从期刊、学校或文档模板。

### 2.2 同处多篇（9.2.1.2）

- 将各序号放在同一对方括号内。
- 离散序号以逗号分隔，如 `[3,7,9]`。
- 连续序号以短横线连接，如 `[12-15]`。
- 混合时可写成 `[3,7,12-15]`。
- 该合并规则不适用于由计算机自动生成圈码的序号。

不要为了缩短而把只有两个不连续号码写成范围。压缩范围时不得改变原引用集合。

### 2.3 多次引用同一文献（9.2.1.3）

- 正文仍标首次序号。
- 后续复引沿用首次序号，不为同一文献另建新号；这是 9.2.1.3 的规则。自动圈码脚注的特殊做法见 2.4。
- 将本次引文页码放在右方括号外，如 `[2]260`、`[2]326-329`；标准示例将该组合整体以上角形式排版。
- 页码不放成 `[2:260]`、`[2,p.260]` 或 APA 式 `[2, p. 260]`。
- 不同复引位置可有不同页码，而文献实体仍是同一条。

### 2.4 自动圈码脚注

脚注方式可由计算机自动生成圈码。此时同一文献再次出现可重复著录；后一次参考文献项可简化为原文献圈码和本次引文页码，如 `④ 同②326-329.`。

保留文档的自动脚注域，不要把圈码机械转换成静态方括号，除非用户明确要求改为普通顺序编码制。

### 2.5 文后表（9.2.2）

- 按正文标注序号依次列出。
- 序号应连续、唯一，并与正文一一对应。
- 不按作者字母或拼音重新排序。
- 没有正文时，不能证明现有排序符合“首次出现顺序”。

## 3. 著者-出版年制

### 3.1 正文基本式（9.3.1.1）

- 标注由责任者姓氏与出版年组成，置于圆括号，如 `(Crane, 1972)`。
- 仅写姓不能识别人名时，可写责任者姓名。
- 集体责任者可写机关团体名称。
- 正文已提到责任者时，紧随其后的圆括号只写年份，如 `Stieg (1981)`。

中文正文可使用与全文一致的中文括号/逗号字形；重点检查责任者、年份和括号语义。

### 3.2 多责任者（9.3.1.2）

- 欧美文献：第一责任者的姓 + `et al.`。
- 中国文献：第一责任者姓名 + `等`。
- 姓氏/姓名与 `et al.`/`等` 之间留适当空隙。

该规则是正文标注规则；文后条目仍按 7.1.2 处理责任者人数。

### 3.3 同一责任者同一年（9.3.1.3）

- 在年份后加小写 `a`、`b`、`c`……。
- 正文和文后表必须使用同一后缀。
- 后缀是文献身份的一部分，不能只在正文或只在文后表出现。
- 标准未单独规定后缀的细分排序算法。若输入没有可靠顺序，按最终文后表的稳定顺序分配，并在变更记录中说明。

### 3.4 多次引用同一文献（9.3.1.4）

- 标注责任者与出版年。
- 将引文页码放在右圆括号外，以角标形式呈现，如 `(机构, 1996)119`。
- 不直接套用 APA 的 `(机构, 1996, p. 119)`，除非用户/刊物明确要求偏离国标。

### 3.5 文后条目年份位置（8.1、9.3）

把出版年移到责任者之后，并以逗号分隔：

`责任者, 出版年.题名[类型].后续字段.`

移动后，从原出版项位置删除该年份，不能重复出现。例如图书出版项由“出版地:出版者,出版年”变为“出版地:出版者”；若有引文页码，仍以冒号接页码。

无责任者时使用 `佚名`/`Anon` 或相应词，以便正文标引和文后排序。

### 3.6 文后表排序（9.3.2）

1. 先按文种集中，可分中文、日文、西文、俄文、其他文种五组。
2. 各组内按责任者字顺，再按出版年排列。
3. 中文责任者可按汉语拼音字顺，也可按笔画笔顺；全文选择一种并保持一致。
4. 文后条目不加顺序编号。这是由第 6.1 条对著者—出版年制首项前置符的规定以及 9.3.2 全部示例归纳出的版式结论，不是 9.3.2 的逐字句子；如出版模板另有编号，应将其识别为模板层附加编号，而非顺序编码制引文号。

标准没有规定“同一处多篇著者-年份引文必须用分号”等额外语法。遇到该情形时服从用户/出版物规则，或保留输入中一致的分隔方式，不把外部格式习惯说成国标硬规则。

## 4. 引文页码

### 4.1 正文标记的位置

| 体系 | 标记 | 页码位置 |
|---|---|---|
| 顺序编码制 | `[n]` | 右方括号外，通常与标记一同以上角呈现 |
| 著者-出版年制 | `(责任者, 年)` | 右圆括号外，以上角呈现 |

### 4.2 文后条目中的页码

- 页码字段前用 `:`；范围用 `-`。
- 期刊引文参考文献写实际引用信息所在页。
- 阅读型参考文献可写文章起讫页或起始页。
- 无页码但有文章编号时，将文章编号放在页码位置。
- 序言或扉页题词可照实际文字著录。

若用户没有指出“全文页码”还是“具体引文页”，不要自动用一个替换另一个。

## 5. 全文闭环检查

### 5.1 顺序编码制检查表

- 收集正文中每个引用标记及首次出现位置。
- 展开 `[2-5]` 后再检查集合。
- 确认首次出现顺序与文后序号一致。
- 确认没有缺号、重号、倒序新号。
- 确认每个正文号有且仅有一个文后实体。
- 确认每个引文型文后条目至少被正文引用一次。
- 将明确标为“延伸阅读”的条目排除于“未引用错误”。
- 检查复引页码位于括号外且与具体引用位置关联。

### 5.2 著者-出版年制检查表

- 规范化责任者显示名后再比对，不要仅按原始字符串。
- 确认正文责任者和年份能唯一命中文后条目。
- 确认 `et al.`/`等` 与第一责任者一致。
- 确认同著者同年后缀完整、唯一、双向一致。
- 确认文后条目年份已移动且未重复。
- 确认文种分组和组内排序。
- 区分机构简称与全称；只有建立明确映射后才视为同一责任者。

### 5.3 去重原则

优先用 DOI、CSTR、URN、专利号、标准号等标识，再结合作者、题名、版本、年份判断。

不要无提示合并：

- 预印本与正式期刊版；
- 在线优先版与正式卷期版；
- 不同版本/语言版本；
- 同一作品的整书与具体章节；
- 同一资源的不同引文页（实体可相同，但引用位置数据不同）。

“一个悬空正文号 + 一个未引用文后号”不是身份依据。只有元数据、旧新编号表、引用管理器键值或用户确认能够证明对应关系时，才可把二者合并并重编号。

## 6. 两种体系互转

### 6.1 顺序编码制 → 著者-出版年制

1. 建立每个旧序号到文献实体的映射。
2. 从条目提取第一责任者、年份和同年消歧信息。
3. 将正文 `[n]` 替换为相应责任者-年份标记；保留每处引文页。
4. 对同一责任者同一年分配 `a/b/c`，同步全文。
5. 删除文后序号，把年份移到责任者后。
6. 按文种、责任者、出版年重排。
7. 再做正文到文后表的一对一核对。

责任者、年份或序号映射缺失时不得猜测；先标为待核。只有文后表、没有正文时，可以转换条目形态和排序，但无法验证每个旧序号的正文替换。

### 6.2 著者-出版年制 → 顺序编码制

1. 建立 `(责任者, 年份+后缀)` 到文献实体的唯一映射。
2. 按正文首次出现顺序分配新序号。
3. 将每处正文标记改为 `[n]`，保留括号外引文页语义。
4. 同处多篇按离散序号和连续范围压缩；自动脚注除外。
5. 把年份移回各类型模板指定位置。
6. 按新序号重排文后表并加方括号序号。

没有正文时不得声称已完成“按首次出现顺序”编号；可提供未编号条目或保留原顺序并明确限制。

## 7. 从其他格式转换

使用“字段中间层”，不要依赖全局标点替换：

| 中间字段 | 典型来源 |
|---|---|
| responsibility | APA/MLA 作者串、BibTeX author、RIS AU |
| title / subtitle | title、booktitle、网页标题 |
| type / carrier | 条目类型、容器类型、URL/介质 |
| host | 期刊、书名、会议、平台 |
| edition / version | edition、version |
| publication | place、publisher、institution、platform |
| chronology | year、full date、accessed |
| locator | volume、issue、pages、article number、archive number |
| access | URL、DOI、URN、CSTR |

转换步骤：

1. 解析并保留所有原始字段。
2. 识别著录对象和主模板。
3. 标记目标标准要求但输入缺失的字段。
4. 只规范有事实依据的字段。
5. 生成条目和正文标记。
6. 输出不可逆变化与待核项。

APA/MLA/Chicago 的作者缩写、题名大小写、容器层级、访问日期和页码语法不能原样搬入；应分别映射到国标字段。

## 8. 无法从片段证明的事项

- 参考文献表片段不能证明顺序编码与正文首次出现一致。
- 正文片段不能证明全文没有漏号或悬空条目。
- 单条记录不能证明著者-出版年表的文种分组和排序。
- 没有资源本身不能证明元数据真实，只能判断结构是否自洽。
- 没有版式信息不能证明方括号标记是否应以上角呈现。

在结论中明确这些限制，不把“未发现”写成“已完全符合”。
